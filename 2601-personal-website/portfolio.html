CS2 Float Trade-Up Calculator

React Web Application

A React-based trade-up calculator for Counter-Strike 2 that calculates precise float values of possible knife outcomes. Users select 5 red-tier skins, input their float values, and the app calculates which knives are possible based on the case collection system.

Key Features:

  • Manually-verified float ranges for 556+ knife skins across 20 knife types
  • Accurate normalized float calculations using proper formulas
  • Handles float range mismatches (e.g., 0.00-1.00 input → 0.01-0.08 output)
  • Comprehensive data structure with 49 cases and multiple gun categories
  • Modular component architecture with organized data files
Status: In Development - Phase 1: Data Setup
